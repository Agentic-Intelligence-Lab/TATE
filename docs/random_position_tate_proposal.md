# 随机初始位置下的 TATE：方案与初步数据审计

> 本文保留首次 29 条 ego 的历史分析。完整 100 条数据的新算法与实验见 [完整实验报告](random_position_tate_full_experiment.md)。

本文建议保留事件分段和最小弯曲传播，把校正目标从“绝对位置锚点分布”改为“场景条件下的残差/物体相对位姿”。先上线可解释的小模型基线，再用场景几何解决逐条轨迹的正确性。尚未实现或验证最终校正算法。

## 2. 现有实现的具体限制

`correction/fit.py` 对每个事件独立拟合 3D 高斯；`correction/apply.py` 的 `_sample_target` 只支持 mean/sample。

取均值时，抓取目标与本条视频中的方块位置无关；独立采样时，虽然恢复了总体变化，却不能保持视频与动作一致，也破坏抓取、放置、方向之间的联合关系。随机位置下，这两种行为不能作为主方案。

`correction/fit_rotation.py` 对 ego 与真机进行全组合配准，再拟合单个局部旋转偏置。位置变化如果伴随抓取角度变化，全组合可能把任务差异误认为姿态偏差。需要先按场景条件或物体相对姿态比较。

`correction/methods/anchors.py` 的传播层可以继续复用，但它默认给未指定的首尾帧添加零位移控制。若前一步是全局外参或尺度校准，全轨迹都应先变换；不能再用零位移首尾抵消这个变换。零端点最多约束后续局部残差。

## 3. 实际数据告诉了我们什么

100 条真机的关键点标准差（cm）：

| 事件 | x | y | z |
|---|---:|---:|---:|
| 抓取闭合 | 5.23 | 4.16 | 0.66 |
| 放置张开 | 0.57 | 0.53 | 0.74 |

这与“方块位置随机、盘子位置较固定”一致，但事件点不是物体位置真值。抓取的平面变化主要是需要保留的任务变化；放置点可采用更强的集中约束，仍需确认盘子是否固定。

29 条 ego 的抓取点 x/y 标准差为 4.60/2.24 cm。不能据此立即把 y 放大约两倍：前 29 条可能覆盖范围不同，也可能有重建尺度误差，需要完整数据与场景位置才能区分。

用所有当前 ego 拟合源均值，每次随机抽 20 条真机拟合目标均值，其余 80 条仅用于计算分布距离；重复 20 个种子。下表为固定 256 个投影方向的平均一维 Wasserstein 距离（SWD，cm，越低越接近），**不是配对位置误差，也不是成功率**。

| 锚点处理 | 抓取 SWD | 放置 SWD | ego 抓取 XY 散布 |
|---|---:|---:|---:|
| 原始 | 6.13 | 7.01 | 5.02 |
| 每个锚点直接替换为真机均值 | 3.08 | 0.49 | 0.00 |
| 每类锚点各自学习共享平移 | **1.20** | **0.34** | **5.02** |
| 用放置点偏移平移全部锚点 | 2.87 | 0.34 | 5.02 |
| 每个锚点只校正 z 均值 | 5.41 | 4.55 | 5.02 |
| 沿相机射线投影至真机平均锚点高度 | 6.89 | 7.34 | 4.30 |

XY 散布定义为 `sqrt(var(x)+var(y))`，使用 population variance。共享平移没有改变任何两个 ego 抓取锚点之间的相对位移。抓取 SWD 的跨种子标准差：原始 0.12 cm、均值目标 0.11 cm、共享平移 0.24 cm；这些不是独立实验的置信区间。

结论范围：事件相关的平移是值得保留的第一基线；单一全局偏移、单纯高度修正尚不足以解释当前分布差异。这里的射线实验只检验“射线与经验高度面相交”，不等于否定所有 ray-depth 模型。尚未校正整条轨迹、验证姿态、计算碰撞/IK 或训练策略。评估集在本次探索中已被查看，因此后续正式确认需要重新定义未触碰测试集或补采数据。

## 4. 第一版：保留空间差异的事件条件残差

对事件 k，用校准真机和源 ego 估计偏移：

```
b_k = mean(real_anchor_k) - mean(ego_anchor_k)
target_ik = ego_anchor_ik + b_k
```

将 `target_ik - ego_anchor_ik` 送入现有最小弯曲传播即可。部署到未来 ego 时冻结 b，不对新测试批次重新拟合。

这是最小改动：从“学目标在哪里”变成“学这类事件通常偏了多少”。每条 ego 的随机位置保留了下来。全分布相同、误差近似加性是它的工作假设；有限样本的摆放差异也会混入 b，因此不能仅凭 SWD 证明它正确。

推荐先用均值版本复现审计，再比较稳健均值/截尾估计。使用 episode 级 bootstrap 检查 b 的不确定性。20 条真机优先按独立观测的方块位置覆盖工作区；若做位置分层抽样，分布拟合要记录采样策略并加权，不能把刻意均匀覆盖的样本当作原始频率分布。

有独立场景位置 c 后，逐步扩展为 `b_k(c)=b_k+B_k(c-c0)`，对 B 强正则，先试低维线性模型。没有条件或对应信息时，不能直接拿不同场景的点作差来回归 B。20 条参考暂不支持高容量神经网络或复杂 GMM。

## 5. 推荐的目标方案：场景条件锚点 + 原轨迹残差传播

### 5.1 条件来自场景，而不是仅来自被校正的手轨迹

为每条轨迹建立 `c=(方块初始位姿, 盘子位姿, 桌面平面, 必要时相机位姿)`。在抓取前方块未遮挡的帧、释放后盘子清晰的帧中估计，并融合多帧。

若保存了标定 RGB-D，可以使用深度与桌面几何；只有 RGB 时，使用已知尺寸、桌面标定或其他可验证约束。EEF 文件中的相机内参不意味着原始深度图已保存。本次尚未核实深度数据是否存在。

不要只用原始 ego 抓取点作为“方块位置真值”，否则无法独立辨识重建误差。可以作为临时代理条件，但必须承认这种循环依赖，并限制校正幅度。

### 5.2 从真机学习物体相对 TCP 关系

对每个真机样本，在各自场景下计算：

```
G_grasp_j = inverse(T_cube_j) @ T_tcp_grasp_j
G_place_j = inverse(T_plate_j) @ T_tcp_release_j
```

拟合低维、稳健的相对位姿分布；再在每条 ego 的场景中恢复目标：

```
T_target_grasp_i = T_cube_i @ G_grasp(c_i)
T_target_release_i = T_plate_i @ G_place(c_i)
```

这不要求真机与 ego 一一配对，只要求两域都能估计物体/盘子坐标系，并且共享相应的抓取方式。方块只有位置、没有可靠朝向时，不要伪造完整 SE(3) 坐标系；使用平移 + 桌面法向，抓取 yaw 另行建模，并考虑方块旋转对称性。

物体相对运动表示已有 TP-GMM/任务参数化学习的研究基础；这里借用它的表示思想，传播层仍保留 TATE，暂不必引入完整 TP-GMM。

### 5.3 区分偏差、任务变化与噪声

- 外参/全局几何误差：用场景几何先校准，不能从单个固定放置点恢复完整旋转或尺度。
- 随方块位置变化的真实运动：保留，或用当前方块坐标系恢复。
- 手到 TCP 的定义偏差：在局部坐标系拟合；不能直接把所有姿态差异归为同一个偏置。
- 遮挡、跟踪跳变、事件时刻偏差：降低权重、修复或排除。

真实位置方差大不代表观测不可靠。抓取 XY 变化来自随机摆放；不能直接把该总体协方差的逆当作测量置信度。先条件化/减去场景变化，再估计残差协方差。

### 5.4 传播与姿态

令预校准后的轨迹为 p(t)，局部修正为 d(t)，事件修正为 Δ_k：

```
min_d Σ_k ||d(t_k)-Δ_k||²_(W_k)
      + λ ∫ ||d''(t)||² dt + μ ∫ ||d(t)||² dt
```

W_k 应来自事件定位、物体检测、重建质量的置信度与残差不确定性。可对抓取平面位置、高度、放置容器约束使用不同权重。低置信度事件使用软约束。加入桌面/容器碰撞、工作空间和 IK 可达性检查；接触阶段与自由运动阶段的几何约束不同。

姿态使用同一坐标约定：`δθ_k=Log(R_ego_k^T R_target_k)`，传播切空间小残差后 `R'_t=R_t Exp(δθ_t)`。大角度或多模态抓取使用分阶段流形优化，不能直接线性平均欧拉角。世界外参旋转通常左乘，工具局部偏置通常右乘，两者要区分。

当前最小弯曲按帧索引定义二阶差分。跨帧率/不同持续时间比较时应以实际时间或明确的阶段进度离散化，并重设正则强度。事件对齐只负责时间语义，不能把不同方块位置强行变成空间对应。

原视频维持不变时，最终目标必须与该视频中的物体一致。把动作搬到另一条真机场景，即使轨迹看起来合理，也会制造错误的图像—动作训练样本。

## 6. 只有 EEF、没有物体定位时：受约束分布校准

可以用现有数据探索联合锚点向量（抓取/放置位置、二者差向量、少量相位形状特征），建立偏移、正则化尺度或条件 OT 模型。但它的角色是弱监督估计，而不是产生配对真值。

候选代价应结合可靠的场景条件、事件语义、相对几何和已有坐标校准；限制映射接近已有几何，保留邻域关系和整体抓放关联。20 对 100 应使用允许多对多的传输计划；不能用强制一对一匹配。尽量在低维条件空间匹配，避免直接对高维整轨迹做最优运输。

OT 的 barycentric target 可能收缩方差，独立高斯协方差匹配可能把定位噪声当作真实位置变化。正则化 affine/OT 可作为对照，不能仅凭它匹配了均值、协方差或 SWD 就投入使用。

**可辨识性边界：** 对称分布中，交换左右两组抓取点仍可得到相同边缘分布，却抓错每条视频里的方块。因此“100 条两域分布一致”有助于统计校准，但不足以唯一恢复逐条校正。独立场景几何、少量配对/人工位置真值或可信的误差模型至少需要其一。

## 7. 完整数据到齐后的正式验证

1. 冻结 episode 清单、源文件指纹、事件规则和实验随机种子；报告所有失败/排除比例，不静默删难例。检查事件是否位于真实接触附近，统一真机与 ego 的闭合/释放时刻定义。
2. 20 条真机是拟合预算。若用其中一部分选择模型/超参，应在这 20 条内部交叉验证；最终测试集不得参与拟合或选择。此次探索已看过全体真机统计，需要把当前 100 条视为开发数据，或补充新的确认性测试集。
3. 分别报告 transductive（待校正 ego 分布可参与拟合）和 inductive（源 ego 拟合/验证/测试分离）。若实际目标是 20 条 ego 学校正，就固定这 20 条作为源拟合集，剩余 80 条不得估计均值或协方差。
4. 基线：原始、当前均值、当前随机采样、事件共享平移、受正则 affine/联合 OT、场景条件相对锚点。位置与姿态分别消融，使用相同传播方法公平比较。
5. 主要指标：独立测量下的抓取点—方块接触偏差、相对姿态误差、放置是否在盘内、图像—动作一致性、IK/碰撞率、轨迹速度与加速度。绝对 TCP 误差需要已知相应目标，不能用任意真机轨迹充当 ground truth。
6. 辅助指标：条件分布 SWD/MMD、覆盖率、邻域/排序保持率、抓放联合关系、校正幅度；报告 real20→real_holdout 的有限样本参考距离。无配对时，全组合绝对位置 DTW 会惩罚合理的位置变化，不宜当主要结论。
7. 泛化：按真实方块位置划分空间区域留出，单独测试边界/外推，防止随机 split 只测到邻近插值。
8. 下游以相同策略、训练预算和种子比较实际任务成功率；不能从轨迹分布指标推断控制成功率。

## 8. 建议的代码落点

- 新增 residual/conditional 拟合 artifact：保存两域拟合集、场景条件来源、映射参数、残差协方差、覆盖范围与指纹。
- 在 `correction/apply.py` 或独立 entrypoint 中生成每条 ego 的条件目标，复用现有传播函数。`preprocess/batch/corrections.py` 已提供外部 entrypoint，不必立即改旧 artifact 语义。
- 独立新增场景条件提取与审核；评估增加 object-relative/conditional 指标，保持旧基线可复现。
- 先完成共享平移 + 现有最小弯曲的整轨迹基线，再实现物体相对锚点；以数据决定是否需要更复杂的局部线性/OT。
